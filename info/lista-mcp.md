# Lista de MCPs

## Quarkus

- **Google Calendar** — Integración con Google Calendar.
  [Enlace](https://mcp.so/server/google-calendar-mcp/adalbertdb)

- **Control de aplicaciones Quarkus** — Crear, desarrollar, ejecutar, monitorizar, mantener actualizada e interactuar con la aplicación en ejecución.
  [Enlace](https://github.com/quarkusio/quarkus-agent-mcp)

- **Interactuar con Bases de Datos** — Inspeccionar tablas, hacer consultas y, si se permite, modificar datos.
  [Enlace](https://github.com/guanghuang/jdbc-mcp)

- **Filesystem** — Servidor de sistema de archivos que se puede utilizar para servir archivos desde un sistema de archivos.
  [Enlace](https://github.com/guanghuang/quarkus-mcp-servers/tree/main/filesystem)

- **JFX Servidor** — Expone un lienzo que se puede utilizar para realizar dibujos mediante JavaFX.
  [Enlace](https://github.com/guanghuang/quarkus-mcp-servers/blob/main/jfx/README.md)

- **Kubernetes** — Permite que los Large Language Models (LLM) interactúen con un clúster de Kubernetes.
  [Enlace](https://github.com/quarkiverse/quarkus-mcp-servers/tree/main/kubernetes)

- **Contenedores** — Permite que los LLM interactúen con contenedores Podman/OCI/Docker.
  [Enlace](https://github.com/quarkiverse/quarkus-mcp-servers/tree/main/containers)

- **Generador OpenAPI a MCP** — Convierte automáticamente cualquier API REST (definida en OpenAPI/Swagger) en un servidor MCP listo para usar.
  [Enlace](https://github.com/LostInBrittany/swagger-to-mcp-generator)

## No Quarkus

- **Mailtrap MCP** — Proporciona herramientas para enviar emails transaccionales y gestionar plantillas de email.
  [Enlace](https://github.com/mailtrap/mailtrap-mcp)

- **BrowserBase** — Permite a los LLM interactuar con páginas web, tomar capturas de pantalla, extraer información y realizar acciones automatizadas con precisión atómica.
  [Enlace](https://github.com/browserbase/mcp-server-browserbase)

- **BlenderMCP** — Permite a Claude interactuar directamente con Blender y controlarlo. Posibilita el modelado 3D asistido, la creación de escenas y la manipulación de datos.
  [Enlace](https://github.com/ahujasid/blender-mcp)

- **Serper MCP Server** — Permite a los LLM obtener resultados de búsqueda de Google.
  [Enlace](https://github.com/garylab/serper-mcp-server)

- **HowToCook-MCP** — Convierte al asistente de IA en un chef personal para planificar las comidas del día a día.
  [Enlace](https://github.com/worryzyy/HowToCook-mcp)

- **mcpadvisor** — Servicio de descubrimiento y recomendación que ayuda a los asistentes de IA a explorar servidores MCP usando consultas en lenguaje natural.
  [Enlace](https://github.com/istarwyh/mcpadvisor)

- **302AI Image** — Servidor Model Context Protocol para generar imágenes utilizando la API 302AI.
  [Enlace](https://github.com/302ai/302_image_mcp)

- **302AI File Parser** — Analiza varios formatos de archivo utilizando la API 302.AI (requiere clave `302AI_API_KEY`).
  [Enlace](https://github.com/302ai/302_file_parser_mcp)

- **3D Cartoon Generator & File System Tools** — Genera imágenes de dibujos animados en 3D utilizando la IA Gemini de Google y proporciona operaciones seguras del sistema de archivos.
  [Enlace](https://mcpservers.org/servers/falahgs/mcp-3d-style-cartoon-gen-server)

- **VideoAnimado** — Ejecuta código de animación Manim y devuelve el vídeo generado. Permite enviar scripts Manim y recibir la animación renderizada.
  [Enlace](https://github.com/Gorav22/Animated_video)

- **Audioscrape** — Busca cualquier audio en segundos.
  [Enlace](https://mcp.audioscrape.com/)

---

> Los elementos marcados con `*` en la lista original están conservados en el orden y contenido.
